# Attribution

Sensify is an original skill system influenced by ideas in Matt Pocock's public `skills` repository, particularly:

- `grilling`
- `grill-me`
- `grill-with-docs`
- `domain-modeling`

Those skills helped motivate several architectural ideas used here, including dependency-aware questioning, separating discoverable facts from user decisions, explicit recommendations, and persistent domain understanding.

Sensify broadens those ideas for general knowledge work and adds a typed epistemic model, research protocol, challenge protocol, persistence abstraction, risk/assumption audits, decision reopening rules, decision-ready completion criteria, and a business-specific understanding model.

Source repository: `mattpocock/skills` on GitHub.

At the time Sensify was created, the source repository declared the MIT license. This file is attribution, not a declaration of the license for this repository. No license has yet been selected for this repository.

Define Requirements was informed by Matt Pocock's `to-spec` and `to-tickets` workflow and pstack's emphasis on observable verification. Its instructions were written for this repository's product-definition handoff; no source skill text was copied.
